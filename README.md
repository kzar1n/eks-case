   # Kubernetes Case Study – EKS + Terraform + GitHub Actions

   Este projeto tem como objetivo servir de case para estudo de:
   - Kubernetes (cluster local e EKS)
   - Terraform (infra como código)
   - GitHub Actions (CI/CD)
   - Microserviços em arquitetura distribuída

   ## Estrutura inicial
   - `infra/`: configurações de infraestrutura
   - `services/`: microserviços
   - `.github/workflows/`: pipelines CI/CD
